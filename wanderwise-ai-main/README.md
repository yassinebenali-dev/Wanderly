# Wanderly – AI-Powered Travel Planning Assistant

## About the Project

Wanderly is an intelligent web platform dedicated to travel planning. It integrates a conversational AI assistant that allows users to prepare their trips simply and intuitively.

Users can specify their destination, travel dates, budget, and personal preferences (accommodation type, activities, cultural and culinary interests). The system then generates personalized recommendations organized into structured sections: accommodation, dining, leisure activities, and cultural or historical information about the chosen destination.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui

## Getting Started Locally

Make sure you have **Node.js** and **npm** installed — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
```sh
# Step 1: Clone the repository
git clone https://github.com/YOUR_USERNAME/wanderly.git

# Step 2: Navigate to the project directory
cd wanderly

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

Then open your browser at `http://localhost:8080` or `http://localhost:5173`
